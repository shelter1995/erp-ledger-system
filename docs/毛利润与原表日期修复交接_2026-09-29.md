# 毛利润与原表日期修复交接

## 计算和筛选口径

- 原表明细按各自 F 列销售订单日期筛选，跨年度导入不覆盖其他明细日期。销售订单总额汇总 W 列对应的订单金额。
- 毛利润统一为 W－AC－BL＋BM。BN 仅保留为原始证据，不直接参与汇总。
- 原表计算保留 W、AC、BL、BM 精度，汇总后四舍五入到分；编辑器金额和销售订单总额继续使用已有两位小数金额。不能先将每行毛利润舍入后汇总。
- 原表空税金和空退税按 0；普通录入未指定税金时，沿用销项税减进项税计算税金。修改订单或采购金额后，新毛利润使用修改后的金额。
- 首页、详情、趋势和导出采用同一计算口径，导出同时保留税金和退税。

## 升级行为

后端启动时增加明细日期和毛利润计算字段，并从已有 `ledger_raw_row` 归档回填。初始化标记保证重启不覆盖已修正税金、金额或日期。恢复旧备份时执行相同回填；新备份保留修正后的计算字段。通常无需重新导入 Excel。

部署代码与修正业务数据是两项操作。升级读取的是导入时归档，不会自动读取桌面上后来修改的 Excel，也没有将本次两笔具体税金硬编码为启动迁移。服务器若仍保存旧归档，单独部署代码不能补齐这两笔税金。
