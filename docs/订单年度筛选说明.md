# 订单年度筛选

首页仪表盘、台账管理、基本信息、销售信息、采购信息默认加载北京时间的当前年度。年度在本次登录期间跨页面共享，刷新页面重新进入时恢复本年；重置也恢复本年。

年度依据销售订单日期。原表导入明细沿用各行自己的订单日期；在线新增明细使用所属销售订单日期。销售回款、采购付款以及开票日期是独立条件，与订单年度取交集。无订单日期的数据仅在“全部年份”出现。

筛选区第一项为订单年度，提供权限范围内已有数据的历史年份和全部年份。宽屏四列、中屏两列、窄屏单列；日期区间占两个字段位置并保持起止日期成组。年度变更立即重新请求，原有查询按钮继续应用其他条件。

后端列表、总数、汇总、订单选择、项目详情与导出支持 order_year 参数，在数据库查询时限制日期范围。兼容旧接口：未传此参数代表全部年份。前端首次请求直接携带本年；切换年度取消旧请求，旧分页结果不再覆盖新范围。

本地验证覆盖跨年、空日期、原表日期与在线订单日期、回款/付款日期交集、部门权限隔离、分页、项目详情和导出。浏览器使用真实组件的静态布局预览检查四列与单列排列；未在生产环境执行 25000 行数据压测。

本地验收：重启后端并刷新浏览器，检查五个页面默认本年；切换历史年份与全部年份；重置后回到本年；核对跨年回款/付款和导出总额。无需为本次年度筛选单独迁移数据库。
